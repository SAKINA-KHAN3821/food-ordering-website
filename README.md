# 🍕 FoodChow - Simple Restaurant Website

A **professional, fully functional** restaurant website built with pure HTML, CSS, and JavaScript.

## ✨ Features

- ✅ **Beautiful UI** - Modern, professional design
- ✅ **Fully Responsive** - Works on all devices
- ✅ **Indian & British Food** - 24 delicious menu items
- ✅ **Shopping Cart** - Add/remove items, update quantities
- ✅ **Local Storage** - Cart persists on page reload
- ✅ **Smooth Animations** - Professional transitions
- ✅ **Contact Form** - Get in touch section
- ✅ **No Dependencies** - Pure vanilla JavaScript
- ✅ **Easy to Customize** - Simple code structure

## 🚀 How to Run

### Super Easy - Just 1 Step!

**Double-click `index.html`** - That's it! The website will open in your browser.

### Or

1. Open the `simple-website` folder
2. Right-click on `index.html`
3. Choose "Open with" → Your browser (Chrome, Firefox, Edge, etc.)

## 🎮 Features Explained

### Menu System
- **24 Food Items** - Indian, British, Desserts, Drinks
- **Category Filter** - Filter by food type
- **Beautiful Cards** - Each item has image, description, price

### Shopping Cart
- **Add to Cart** - Click "Add" button on any item
- **Update Quantity** - Increase/decrease with +/- buttons
- **Remove Items** - Delete icon on each cart item
- **Persistent** - Cart saved in browser (survives page refresh)
- **Total Calculation** - Automatic price calculation

### Responsive Design
- **Mobile** - Hamburger menu, stacked layout
- **Tablet** - Optimized grid layout
- **Desktop** - Full featured layout

## 🎨 Customization

### Change Colors
Edit `styles.css` - Look for `:root` variables:
```css
--primary-color: #ef4444;  /* Change this */
--secondary-color: #1f2937;
```

### Add More Food Items
Edit `script.js` - Add to `menuData` array:
```javascript
{
    id: 25,
    name: "Your Dish",
    category: "indian", // or "british", "desserts", "drinks"
    price: 9.99,
    image: "image-url-here",
    description: "Description here"
}
```

### Change Restaurant Info
Edit `index.html` - Update contact section, about section, etc.
